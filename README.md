# 乌鲁木齐 Citywalk 行程地图

这是可直接部署到 GitHub Pages 的静态网站包。

## 部署方法

1. 在 GitHub 新建一个公开仓库。
2. 将本压缩包解压后的全部文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/(root)`，然后点击 **Save**。
6. 等待约 1–3 分钟，GitHub Pages 页面会显示网站访问地址。

网站入口文件为 `index.html`。请保持它位于仓库根目录。

## 说明

- 网站为纯静态页面，不需要安装依赖或执行构建命令。
- 地图底图、地图组件以及外部导航链接需要网络连接。
- 若首次打开地图未显示，可刷新页面或切换网络后重试。
